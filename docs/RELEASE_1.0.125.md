# Potato Launcher v1.0.125 — in-game cap for every client by default

- "Main: exact 60 via NVIDIA cap" is now **off by default**. The game's own 60 limit uses less CPU (measured on the main: 6.26% vs 7.07%), so every client, main included, gets it at launch again.
- The option stays available for anyone who prefers an exact 60 on the main over that CPU (Optimizer, top row). A setting saved by 1.0.124 is not carried over.
