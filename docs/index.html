Keep the routine simple.

Pick the accounts you want, save them as a band, and launch them in order. Portraits make the roster easy to scan, and queue controls help keep startup calm.

Bands Launch saved groups with cooldowns and initialization waiting.
Portraits Use Lodestone portraits so each account is easy to recognize.
Updates Install normally and keep settings between releases.

Watch your clients.

Open the Optimizer when you want to see client CPU, GPU, RAM, affinity, and trim status at a glance.

Install and go.

Download the Windows installer from GitHub Releases. Bands, accounts, settings, and portraits stay in your app data folder when you update.
